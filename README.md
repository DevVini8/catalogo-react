# Catálogo e Painel em React.js

Aplicação em React.js contendo:

- **Acordeão (`src/components/Accordion/`)**
- **Paginação (`src/components/Pagination/`)**
- **Barra de Progresso (`src/components/ProgressBar/`)**
- **Abas (`src/components/Tabs/`)**
- **Menu Suspenso (`src/components/DropdownMenu/`)**
- **Notificação Toast (`src/components/Toast/`)**
- **Context API (`src/context/AppContext.js`)**

## Execução

```bash
npm install
npm start
```
